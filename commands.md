# Команды чата Google Antigravity

В этом справочнике собраны **только те команды и операторы, которые вводятся непосредственно в поле ввода чата с AI-агентом** в среде Google Antigravity (Antigravity IDE / Antigravity 2.0).

---

## 1. Слэш-команды чата (`/`)

Слэш-команды активируют специализированные сценарии работы агента, переключают режимы диалога или запускают сложные рабочие процессы:

| Команда | Назначение | Как использовать | Примечание |
| :--- | :--- | :--- | :--- |
| **`/goal <цель>`** | **Автономное выполнение до упора.** Агент работает в режиме максимальной дотошности, самостоятельно планирует, вносит изменения, тестирует и не останавливается, пока задача не будет полностью решена и проверена. | `/goal поправь верстку модального окна и покрой тестами` | Идеально для длительных фоновых и ночных задач. |
| **`/schedule <инструкция>`** | **Планировщик задач.** Позволяет запланировать регулярное выполнение инструкции по расписанию (cron) или установить одноразовый отложенный таймер. | `/schedule каждые 30 минут проверять логи сборки` | Создает отслеживаемый фоновый процесс. |
| **`/grill-me`** | **Режим предварительного интервью.** Агент переходит в режим сбора требований: задает встречные вопросы, выявляет скрытые граничные случаи и согласовывает архитектурный план до написания кода. | `/grill-me проектируем модуль авторизации через WebAuthn` | Защищает от неверных архитектурных решений. |
| **`/learn`** | **Фиксация в долговременную память.** Агент сохраняет важное исправление, архитектурное ограничение или порядок работы в постоянную базу знаний проекта (Knowledge Base / Rules). | `/learn в этом проекте всегда используем Radix Vue для диалогов` | Предотвращает повторение одинаковых ошибок в будущем. |
| **`/boost <задача>`** | **Глубокое мультиагентное рассуждение.** Запуск параллельного анализа для нетривиальных алгоритмических задач, race conditions и трудновоспроизводимых дефектов. | `/boost почему падает сокет при одновременных запросах` | Углубленный многопроходный аудит логики. |
| **`/teamwork-preview <задача>`** | **Командная оркестрация субагентов.** Разворачивает команду взаимодействующих субагентов с разделением ролей (Worker, Reviewer, Critic, Auditor) для решения объемных сквозных задач. | `/teamwork-preview перевести все API эндпоинты на DTO` | Доступно в рамках программы раннего доступа (Ultra Plan / Preview). |

## 2. Контекстные упоминания в чате (`@` Mentions)

При вводе символа `@` в строке чата открывается интерактивное контекстное меню для передачи агенту данных из среды разработки:

| Упоминание | Назначение | Пример использования |
| :--- | :--- | :--- |
| **`@file <путь>`** | Передать содержимое конкретного файла в контекст запроса. | `Поясни логику в @file src/stores/user.ts` |
| **`@folder <путь>`** | Передать структуру папки и список содержащихся файлов. | `Изучи структуру в @folder src/components/ui` |
| **`@problems`** | Передать агенту текущий список ошибок и предупреждений линтера/компилятора из IDE. | `Исправь все ошибки из @problems` |
| **`@terminal`** | Прикрепить вывод или журнал конкретной терминальной сессии. | `Посмотри на ошибку в @terminal и скажи почему упала сборка` |
| **`@git`** | Передать текущий git diff, состояние репозитория или историю коммитов. | `Сделай код-ревью изменений в @git` |
| **`@mcp`** | Обратиться к подключенным ресурсам, базам данных или внешним инструментам по протоколу MCP. | `Запроси схему таблицы через @mcp` |
| **`@conversation`** | Подключить контекст предыдущей беседы для продолжения работы. | `Вспомни контекст обсуждения @conversation и продолжи реализацию` |

## 3. Что НЕ вызывается из чата (вынесено в интерфейс IDE)

В отличие от консольного терминального клиента (`agy`), в чате IDE следующие команды **не используются**, так как для них есть штатные элементы интерфейса:

* **Выбор модели (`/model`)** — переключается через выпадающий список в строке состояния IDE.
* **Политика автономии (`/permissions`)** — настраивается в панели Settings (вкладка политик выполнения команд).
* **Горячие клавиши (`/keybindings`)** — настраиваются через стандартное меню сочетаний клавиш VS Code (`Ctrl+K Ctrl+S`).
* **Просмотр диффов (`/diff`)** — визуальные diff-наложения открываются прямо в редакторе кода.
* **Управление фоновыми задачами (`/tasks`)** — доступно на вкладке Auxiliary Pane (Background Tasks).
* **Открытие файлов (`/open`)** — файлы открываются кликом по ссылкам `file:///...` в ответах агента.
* **Настройка строки состояния (`/statusline`)** — опция исключительно для терминального TUI CLI.
